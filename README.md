# Paid Media Lab Guide

An interactive, single-page guide to paid social media metrics: how CPM, CTR, CPC, CVR, CPA, AOV and ROAS connect, what moves them, and how to read the warning signs.

Live: https://jameschrisa.github.io/paid-media-lab/

## What’s inside

- The metric chain, with plain-language explanations
- Flashcards for nine core terms
- A campaign simulator with report-card grades and automatic diagnosis
- Common failure patterns you can load into the simulator
- Paid-ad budget share by industry, plus a fit check
- A 70/20/10 budget planner
- A seven-question quiz

## Deploy

1. Create a repo named `paid-media-lab` under `jameschrisa`.
2. Upload everything in this folder to the repo root, including `.nojekyll`.
3. Settings > Pages > Deploy from a branch > `main` / root.

If you use a different repo name, replace `paid-media-lab` in `index.html` (canonical, og:url, og:image, twitter:image), `robots.txt`, `sitemap.xml` and this README.

Benchmarks are general rules of thumb and vary by platform, industry, season and audience.
